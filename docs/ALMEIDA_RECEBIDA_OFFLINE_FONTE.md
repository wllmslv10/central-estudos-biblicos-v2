# Fonte da Almeida Recebida (AR) 1.7

Fonte: https://www.almeidarecebida.org/download-portuguese-bible-almeida-recebida-xml/ (17/03/2017).

O projeto descreve o texto como **domínio público**, mas a mesma página exibe aviso **BY-NC-SA**. Por cautela, conservar atribuição, limitar uso da base a fins não comerciais e confirmar a compatibilidade de compartilhamento antes de publicar ou redistribuir o arquivo. O código deste repositório não altera as condições de licença da tradução.

Os scripts de conversão e validação não são prova de que a interface esteja funcionando. Não habilitar a fonte offline em produção antes de instalar o arquivo, validar a leitura e os testes de regressão.
